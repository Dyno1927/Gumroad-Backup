A few answers up front

What do I need? Linux with Python 3.12 and uv, your own Google Cloud project (Gmail API), and a Gemini key. The README in the archive walks you through every step.

Do you see my email? No. It runs on your machine — no Relayzen server, no account. It only ever sends the sender and subject of each message to Gemini, never the body.

Can it delete anything? No. It never asks for the scope that allows permanent deletion. A dry_run flag stops every write, and each decision is logged with its reason.

How accurate is it? Measured: 69/69 legitimate messages kept out of Trash, 24/30 junk binned, ~45% filed in the exact folder. Trust the Trash decision; treat folders as a first pass.

One personal Gmail account per install — this is code you run, not a service I host. But the person who wrote it is the same person reading your message.
